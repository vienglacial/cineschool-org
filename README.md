# CineSchool.ORG Studio

Bản cài đặt dành cho học viên CineSchool.ORG.

## Tải về

Vào mục **[Releases](../../releases/latest)** và tải file `CineSchool-Setup-x.y.z.exe`.

Cài xong app sẽ **tự kiểm tra cập nhật** mỗi lần mở — không cần tải lại thủ công.

## Yêu cầu

- Windows 10 / 11 (64-bit)
- Cài cho người dùng hiện tại, không cần quyền admin

## Ghi chú

Repo này **chỉ chứa file cài đặt**, không chứa mã nguồn.
